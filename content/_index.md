BletchMAME is a front end for [MAME](https://www.mamedev.org/). Unlike existing front ends (most of which function as launchers retaining MAME's internal UI), BletchMAME replaces the internal MAME UI with a more conventional point and click GUI (sometimes described as [W.I.M.P.](https://en.wikipedia.org/wiki/WIMP_(computing))) to provide a friendlier experience in a number of areas (such as favorites, input configuration and a number of others). While BletchMAME is intended to support all machines supported by MAME, it should be particularly suitable to computer emulation.

BletchMAME is licensed under the [GNU GPL](https://www.gnu.org/licenses/gpl-3.0.en.html).
